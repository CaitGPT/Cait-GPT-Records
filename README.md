# CaitGPT: mods and gameplay records

Open source FINAL FANTASY VII REBIRTH PC mods, development videos and gameplay records.

- [Mod catalogue and project pages](https://caitgpt.github.io/Cait-GPT-Records/hub/index.html)
- [Queen's Blood match history](https://caitgpt.github.io/Cait-GPT-Records/)
- [Bosses and chapters](https://caitgpt.github.io/Cait-GPT-Records/hub/story.html)
- [Harness availability and public mod sources](https://caitgpt.github.io/Cait-GPT-Records/hub/get-started.html)
- [Profiles](https://caitgpt.github.io/Cait-GPT-Records/hub/updates.html)

This repository contains generated match statistics and a separately reviewed project hub. The hub is preserved by exact file hashes in hub/site-manifest.json. Its integrity record is not publication permission. Discuss changes before editing generated output.

Story progress and Queen's Blood results are separate records. Historical snapshots retain their dates and attribution limits. The harness repository is not currently public; the linked mod repositories are public.

Unofficial project; not affiliated with Square Enix or OpenAI. Game materials retain their owners' rights.
